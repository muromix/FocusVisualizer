# Focus Visualizer - インストールと設定ガイド (v0.9.9.3 Alpha)

**Created by muromix & Angie**

このドキュメントは、Adobe Lightroom Classic (LRC) 用「Focus Visualizer」のセットアップ手順書です。
v0.9.9.3 Alpha の内容を反映しています。

---

## 🚀 1. システム要件 (準備)

Windows 版は、**Python や Node.js の事前インストールが不要** な「ポータブル版」です。

### 🪟 Windows をお使いの方
- **OS**: Windows 10 / 11 (64bit)
- **依存環境**: 不要（全てパッケージに内蔵されています）
- **Lightroom Classic**: v12.0 以上推奨

### 🍎 Mac をお使いの方
- **Mac**: Apple シリコン搭載の Mac
- **OS**: macOS 13 (Ventura) 以上
- **配布物**: `v0.9.9.3_Alpha_Mac.zip`（Apple の公証は受けていません。初回起動の手順は下の「セットアップ手順 (Mac)」を参照）

---

## 📦 2. セットアップ手順 (Windows)

Windows 版は「解凍して置くだけ」で準備が完了します。

1. ダウンロードした ZIP ファイルを解凍（展開）し、できたフォルダを好きな場所に置きます（例: ユーザーフォルダ内に作った `plugin` フォルダなど）。
   - フォルダの場所（パス）に**日本語（全角文字）や特殊な記号**が含まれていると、正常に動作しない場合があります。Windows のユーザー名が日本語の場合は、ユーザーフォルダ以外の場所に置いてください。
2. Lightroom Classic を起動します。
3. **[ファイル] ＞ [プラグインマネージャー]** を開きます。
4. **[追加]** ボタンをクリックし、解凍したフォルダ内の **`1.Plugin_for_Lightroom/Focus_Visualizer.lrplugin`** フォルダを選択します。
5. ステータスが「有効」になれば完了です。

### セットアップ手順 (Mac)

1. ダウンロードした ZIP ファイルを解凍し、できた `FocusVisualizer_v0.9.9.3_Alpha_Mac` フォルダを丸ごと「アプリケーション」フォルダなど好きな場所に移動します。アプリ本体・プラグイン・説明書がこのフォルダにまとまっています。
2. **初回のみ**: フォルダ内の `Focus Visualizer.app` をダブルクリックします。警告が出たら閉じ、**[システム設定] ＞ [プライバシーとセキュリティ]** を開いて、ブロックされた旨の表示の横の **[このまま開く]** で許可します。「デスクトップ」などのフォルダへのアクセス許可を求められた場合は、許可してください。
3. Lightroom Classic の **[ファイル] ＞ [プラグインマネージャー]** で **[追加]** を押し、フォルダ内の **`Plugins/Focus_Visualizer.lrplugin`** を選択します。
4. 登録後にフォルダを移動すると連携できなくなります。移動した場合は登録し直してください。

詳しい手順は、同梱の `はじめにお読みください (JP).txt` にも書いてあります。

## 🎯 3. 起動方法 (LRC から起動)

本ツールは、Lightroom Classic 内からメニューを呼び出すことで、ビューアーが自動的に立ち上がります。

1. Lightroom Classic のライブラリモジュールで、写真を選択します。
2. **[ライブラリ] ＞ [プラグインエクストラ] ＞ [Focus Visualizer]** をクリックします。
3. ビューアーが自動的に立ち上がり、写真の合焦位置を可視化します。
   - Windows では、起動時にコマンドプロンプトの黒い画面が一瞬表示されることがあります。

## 🛠️ 4. メンテナンスとトラブルシューティング

- **統合ログ (`Logs/`)**:
  バックエンド、Electron、Lightroomプラグインの動作ログが、解凍したフォルダ直下の **`Logs/`** フォルダに出力されます。不具合が発生した際はこの中のファイルを確認してください。
  - Mac では、バックエンドとビューアーのログは `~/Library/Application Support/Focus Visualizer/Logs` に出力されます（Lightroom プラグインのログは、フォルダ内の `Logs/`）。
- **アンインストール**:
  レジストリ等のシステム設定は書き換えません。プラグインマネージャーから削除し、フォルダごとゴミ箱へ捨ててください。
  - Windows では、前回表示していた写真などの記録が `%APPDATA%\Focus Visualizer` フォルダに残ります。不要であれば、このフォルダも削除してください。
  - Mac では、同様の記録とログが `~/Library/Application Support/Focus Visualizer` に残ります。
