# Focus Visualizer - 全体仕様書 (Master Specification - Japanese)

**対象バージョン**: v0.9.9.2 Alpha

## 1. アプリケーション概要 (Overview)
Sony α・Canon EOS で撮影した RAW 画像から、カメラが記録したメタデータ（AF 位置、被写体認識、撮影情報など）を取り出し、Lightroom Classic と連動しながら AF 枠を重ねて表示するビューアーです。

### セキュアな通信基盤 (Secure IPC Foundation)
Electron の推奨設定に沿って、画面側（レンダラー）の権限を最小限にしています。
1.  **コンテキスト分離 (Context Isolation)**: 画面側から Node.js / Electron の機能へ直接触れられないようにしています。
2.  **プリロード・ブリッジ (Preload Bridge)**: `preload.js` で許可した通信だけを `window.api` として画面側に渡します。
3.  **ファイル書き込みの代行**: 画面側はファイルを直接書き込みません。保存はメインプロセスが代わりに行います。
4.  **CSP (Content Security Policy)**: 画面側からの通信先を、手元の PC 内のサーバー（127.0.0.1）に限っています。

## 2. システム構成 (System Architecture)

*   **Lightroom プラグイン (Lua)**: Lightroom で選んでいる写真を見張り、バックエンドへ知らせます。ビューアーで付けたレーティング等を Lightroom へ書き戻します。
*   **バックエンド (Python / Flask)**: ExifTool と rawpy でメタデータとプレビュー画像を取り出し、AF 枠の座標を計算します。
*   **ビューアー (Electron)**: 画像と AF 枠を表示します。詳しくは **[UI 仕様書](./UI_SPECIFICATION.md)** を参照。

**通信**: HTTP + SSE（すべて 127.0.0.1 の中だけ）

### 🔐 セキュリティとプライバシー
- **ローカル完結設計**: 写真の解析はすべて手元の PC の中で行います。外部サーバーとの通信は行いません。
- **ホスト限定通信**: Lightroom・バックエンド・ビューアーの間の通信は `127.0.0.1` (localhost) に限られています。
- **データ収集なし**: 画像データ、閲覧履歴、個人情報などを収集・送信することはありません。

## 3. 主要機能 (Main Features)

### 📸 フォーカス可視化 & 解析
*   **AF 枠の表示**: カメラが記録した AF 位置を枠で表示します（`F` キーで表示／非表示）。
*   **Sony α**: AF 位置に加え、被写体認識の種類（人物・動物・鳥など）や、メーカーノート（Tag9401）に記録された顔の枠を表示します。
*   **Canon EOS**: EOS R シリーズのメタデータから AF エリアを表示します。
*   **フォーカスピーキング**: 表示中の画像からコントラストの強い部分（ピントの合った部分）を検出して重ねて表示します（`P` キー）。しきい値は `↑` / `↓` で調整できます。
*   **日本語パス対応**: 写真のフォルダ名に日本語が含まれていても表示できるよう、文字化けを補正する処理を備えています。

### 🔄 Lightroom 同期
*   **写真の追従**: Lightroom で写真を選ぶと、ビューアーの表示が切り替わります。ビューアーで `←` / `→` を押すと、Lightroom 側の選択も前後に移動します。
*   **評価の書き戻し**: レーティング (`1`-`5`)、カラーラベル (`6`-`9`, `0`)、フラグ（採用／除外）を Lightroom へ反映します。
*   **現像の調整は反映しない**: Lightroom での切り抜き・回転・露出などの調整は表示に反映しません（4章を参照）。

### 💎 画質制御 (Quality Mode)
| モード | 解像度 | 特徴 | 初期値 (Default) |
| :--- | :--- | :--- | :--- |
| **Speed** | 1600px | 速さ優先 | **Full / Lite モード共通の初期値** |
| **Full** | オリジナル | ピントの細部確認 | `Q` キーで切り替え |

*   **ブラウジング検知**: `←` / `→` を短い間隔（280ms 未満）で続けて押している間は、画質設定に関わらず軽い画像だけを表示し、写真送りの速さを優先します。
*   **画質ロック (`L`)**: Full 画質でロックを有効にすると、Full 画質の表示が終わるまで次の写真への移動を待ちます（応答がない場合は約 2.5 秒で解除）。
*   **先読み**: 前後の写真のメタデータを先に読み込み、写真送りを速くします。

### 🪟 Full モードと Lite モード
*   **Full モード**: 画面の右端に開く、情報パネル付きの窓です。
*   **Lite モード**: 常に最前面に表示される小さな窓です。使えるキーは `←` / `→`、`Space`、`Shift + M` に絞られています。
    - **アンロック**: コナミコマンド（`↑ ↑ ↓ ↓ ← → ← → B A`）を入力すると、Lite モードでもレーティング・ラベル・フラグ・画質切替などのキーが使えるようになります（レイアウト切替 `I` を除く）。もう一度入力すると元に戻ります。
*   **マルチディスプレイ対応**: 起動時はマウスカーソルのあるディスプレイに窓を開きます。モード切替やリサイズの際は、いま窓があるディスプレイの中で配置し直します。

## 4. 開発理念：写真選別特化 (Selection Specialized)
本プロジェクトは、汎用的な画像編集ソフトを目指すのではなく、撮影後の膨大な RAW 画像から「ベストショットを速く選び抜く（Culling）」ための専門ツールを目指します。

1.  **カメラが記録したままの画像で確認する**:
    Lightroom での切り抜き・回転・露出などの調整は表示に反映しません。カメラが記録したままの画像に AF 枠を重ねて表示します。
2.  **判断を促す UI**:
    画像を見せるだけでなく、AF 位置や被写体認識（顔・動物・鳥など）の状態を表示し、ピントの良し悪しを迷わず判断できるようにします。
3.  **独立性と軽快さ**:
    Lightroom のプレビュー生成を待たず、RAW ファイルから直接画像とメタデータを取り出して（ExifTool・rawpy）表示します。

## 5. 操作・ショートカットキー (Keyboard shortcuts)
| キー | アクション |
| :--- | :--- |
| `Space` | **ターゲット・ズーム**（全体表示 ↔ 等倍。等倍ではピント位置を中央に表示） |
| マウスホイール / ドラッグ / ダブルクリック | 拡大縮小 / 表示位置の移動 / 全体表示に戻す |
| `←` / `→` | 写真送り（Lightroom 連動） |
| `1` - `5` | レーティング（同じ数字をもう一度押すと解除） |
| `6` / `7` / `8` / `9` / `0` | カラーラベル（赤 / 黄 / 緑 / 青 / 紫） |
| `Backspace` | カラーラベルを外す |
| `A` / `X` / `U` | フラグ（採用 / 除外 / なし） |
| `Q` | 画質モード切替（Speed ↔ Full） |
| `L` | 画質ロック |
| `F` | AF 枠の表示 ON/OFF |
| `P` | **ピーキング** ON/OFF |
| `↑` / `↓` | ピーキングのしきい値の調整 |
| `I` | レイアウト切替（Full モードのみ） |
| `M` / `Shift + M` | **モード切替**（Full ↔ Lite） |

*注: Lite モードでは、アンロックするまで `←` / `→`、`Space`、`Shift + M` だけが使えます。*
